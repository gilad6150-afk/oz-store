# מכון עוז - אתר מסחר חדש (oz-store)

אתר אינטרנט חדש, מודרני ומהיר שנבנה עבור **מכון עוז (מכון לקדושה)**, מותאם ללוגו המותג ומאופיין בחוויית משתמש (UX) מותאמת להגדלת מכירות.

## 🚀 תכונות עיקריות
- 👑 **עיצוב מותג יוקרתי:** מותאם 100% ללוגו מכון עוז בגווני סגול מלכותי (`#6A459E`), לבן וסלייט.
- 📦 **50 המוצרים האמיתיים:** ייבוא מלא של 50 המוצרים מהאתר הקיים (תפילין, מזוזות, ארנקים, ספרים וסידורים).
- 🚚 **מד התקדמות למשלוח חינם:** מעודד לקוחות להגדיל את סל הקניות (Cross-sells / Free Shipping Bar).
- 🔍 **חיפוש בלייב (Live Search Modal):** חיפוש מהיר בזמן אמת של מוצרים.
- 📱 **התחברות מהירה בשם + נייד:** ללא סיסמאות מורכבות, כולל שמירת פרטים למערכת SMS.
- ❤️ **רשימת מועדפים (Wishlist):** כפתור לב מובנה על כל מוצר.
- 🛒 **עגלה נשלפת עם ברכות אישיות:** ברכות מתחלפות לפי שעות היממה (*"בוקר טוב", "ערב טוב"*).

## 📁 מבנה הקבצים
- `index.html` - עמוד הבית והחנות הראשי.
- `products_data.js` - בסיס הנתונים של 50 המוצרים.
- `public/oz_logo.png` - לוגו המותג הרשמי.
- `start_server.ps1` - סקריפט להרצה מהירה בדפדפן.
